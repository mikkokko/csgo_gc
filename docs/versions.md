# Version support

## 2023

The [standalone version of the game](https://store.steampowered.com/app/4465480/CounterStrikeGlobal_Offensive/) is supported.

## 2013

Version 1.30.0.1 (Aug 15 2013, shortly after the Arms Deal update) has been tested. This version has a slightly different price sheet format, so the store prices are going to be broken if using the price_sheet.txt provided in csgo_gc releases.

## Anything in between

Untested, but should work for the most part. If you encounter version specific bugs or issues, feel free to open an issue.
